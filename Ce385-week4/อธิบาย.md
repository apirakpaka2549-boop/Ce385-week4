# สรุปคำอธิบาย Workshop 3

* **ข้อ 1 (Error-First Callback):** ออกแบบตามมาตรฐาน Node.js โดยใช้พารามิเตอร์ตัวแรกรับ Error (`err`) และตัวที่สองรับข้อมูล (`data`) หากมีข้อผิดพลาดให้ส่ง `callback(err)` หากสำเร็จให้ส่ง `callback(null, data)`
* **ข้อ 2 (Callback to Promise):** ห่อหุ้มฟังก์ชันอ่านไฟล์ด้วย `new Promise()` เพื่อแก้ปัญหา Callback Hell โดยเรียก `resolve(data)` เมื่อสำเร็จ และใช้ `reject(err)` เมื่อเกิดข้อผิดพลาด เพื่อให้รองรับ `.then()` และ `.catch()`
* **ข้อ 3 (Async/Await):** ใช้ `fs/promises` ร่วมกับคีย์เวิร์ด `async/await` เพื่ออ่านไฟล์ใน Array ทีละไฟล์ตามลำดับ ให้โค้ด asynchronous ทำงานอ่านง่ายเหมือนแบบ synchronous พร้อมใช้ `try...catch` ครอบเพื่อดักจับ Error
* **ข้อ 4 (EventEmitter):** สืบทอดคลาส `EventEmitter` เพื่อสร้างระบบ Event-Driven โดยใช้ `this.emit()` กระจาย Event (`done` หรือ `error`) ออกไปเมื่อทำงานเสร็จ และใช้ `.on()` รอรับ Event มาประมวลผล
